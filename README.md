### 📌 Nama Aplikasi

# **KRS Online**

Aplikasi mobile untuk mempermudah proses pengisian Kartu Rencana Studi mahasiswa secara digital.

---

### 🚀 Gambaran Umum

KRS Online merupakan aplikasi mobile yang dikembangkan untuk menyederhanakan alur pengisian Kartu Rencana Studi (KRS) bagi mahasiswa. Aplikasi ini menyediakan daftar mata kuliah beserta informasi jadwal, SKS, kapasitas kelas, dan status ketersediaan secara real time. Pengguna dapat melakukan filter dan pencarian mata kuliah, memilih kelas, serta mengelola daftar rencana studi melalui keranjang KRS.

Jika kapasitas suatu kelas penuh, sistem menyediakan mekanisme waiting list untuk menampung pendaftar tambahan hingga terjadi perubahan. Mata kuliah yang telah dipilih akan tersusun otomatis dalam bentuk visualisasi jadwal mingguan dengan tampilan yang ringkas dan informatif. Pengembangan aplikasi menggunakan Flutter sebagai framework front-end dan Firebase sebagai backend untuk mendukung performa, skalabilitas, serta akurasi data akademik secara efisien.
